# Something Clicks

Referral lead engine for commercial cleaning walkthroughs in the Salt Lake Valley.

- Businesses request a walkthrough (directly or through a referral partner's link).
- Commercial cleaning companies ("buyers") sign up, get approved, and prepay for appointment credits with Stripe.
- Referral partners apply; approved partners get a PromoteKit affiliate account (coming in Phase 2).

Stack: Next.js (App Router, TypeScript) on Vercel · Supabase (Postgres, Auth, RLS) · Stripe · Resend.
